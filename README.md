
# 🚀 datapilot-cli
### Terminal File Commander + CSV Data Doctor
Powered by Rich + Pathlib + Shutil + Pandas

> Where am I? What files? Copy, Move, Rename, Delete with safety checks, plus CSV missing values & cleaning — all in a beautiful Rich loop menu.

#### Features
- [1] Check Exists: auto-find files anywhere
- [2] Inspect File: size, extension, modified date + CSV preview
- [3] List Folder: show files inside with sizes
- [4] Backup: timestamped backup to backups/
- [5] Create File
- [6] Create Folder
- [7] Copy file to folder
- [8] Delete file/folder with y/n confirmation
- [9] Check missing values in CSV
- [10] Check duplicates in CSV
- [11] Clean and save CSV as cleaned_*.csv
- [12] Exit

#### Run
pip install -r requirements.txt
python datapilot_cli.py
